Contenedor de superficie con tres regiones opcionales: .card__header (titulo/eyebrow + acciones), .card__body (contenido principal) y .card__footer (acciones o metadatos). Modales

Modal / Dialog

Raiz overlay (.modal) que ocupa el viewport y pinta el scrim (--color-overlay). Dentro, un contenedor centrado (.modal__dialog) con superficie (--color-surface), radio y sombra. El dialog se compone de tres regiones opcionales: .modal__header (titulo .modal__title + boton de cierre .modal__close), .modal__body (contenido scrolleable) y .modal__footer (zona de acciones alineadas a la derecha). El header puede llevar un icono de tono semantico (.modal__icon) para variantes danger/success/info/warning. El conjunto se asocia por aria a un titulo y, opcionalmente, a una descripcion.

Variantes: Por tamano: .modal__dialog--sm (max 420px, confirmaciones), --md (max 560px, por defecto), --lg (max 760px, formularios densos), --full (casi pantalla completa con margenes minimos), Por tono semantico del header/icono: .modal__dialog--danger | --success | --warning | --info (afecta color del icono y del titulo), alertdialog: role="alertdialog" + data-dismissible="false" para confirmaciones criticas que no se cierran por scrim/Escape, Sin footer (solo body informativo) o sin header (contenido autocontenido)  ·  Estados: cerrado: display:none, no participa del foco ni del tab order, abierto (data-open): visible, scrim opaco, dialog con animacion de entrada (escala + fade), scroll-body: cuando el contenido excede la altura, .modal__body hace scroll y header/footer quedan fijos, focus-trap activo: el foco queda confinado dentro del dialog (gestion via JS del consumidor), hover/active/focus-visible en .modal__close y en los botones del footer

Modal Trigger (disparador)

Elemento accionador (normalmente un .btn) que abre un modal por referencia. Expone la relacion mediante atributos de control: aria-haspopup="dialog" y aria-controls apuntando al id del overlay .modal. Refleja el estado del modal con aria-expanded. No aporta estilos propios: reutiliza la familia de botones; aqui se documenta unicamente el contrato de atributos para que el JS del consumidor cablee apertura/cierre y la restauracion de foco.

Variantes: Cualquier variante de boton del DS puede actuar como trigger (.btn--primary, .btn--secondary, .btn--ghost, .btn--danger), Trigger de cierre interno: usar data-modal-close en cualquier elemento dentro del .modal (el propio .modal__close, botones del footer o el scrim)  ·  Estados: reposo: aria-expanded="false", modal abierto: aria-expanded="true" (el consumidor lo actualiza al abrir), al cerrar el modal, el foco se restaura sobre este trigger (gestion del consumidor)

Progress bar

Bloque .progress que opcionalmente agrupa una cabecera .progress__header con .progress__label (texto del canal) y .progress__value (porcentaje/conteo). La pista .progress__track es el carril de fondo; dentro va .progress__bar (relleno) cuyo width refleja el avance. El conjunto es el elemento ARIA con role=progressbar y aria-valuenow/min/max. Variante por canal mediante modificador (progress--telegram, progress--whatsapp) o color semantico (progress--success/--warning/--danger). Soporta modo indeterminado (progress--indeterminate, sin aria-valuenow).

Spinner / loader inline

Elemento unico .spinner: un circulo con borde parcial que rota (role=status para anuncio accesible). Puede acompanarse de texto visible (.spinner-inline agrupa spinner + .spinner__text) o de texto solo para lectores de pantalla (.sr-only). Variante de tamano por modificador y color heredado (currentColor) o por tono. Para botones en carga se reutiliza dentro del boton (el componente Boton expone .btn--loading; aqui se ofrece el atomo reutilizable).

Variantes: spinner--xs / --sm / --md / --lg (tamano), spinner--primary / --muted / --on-primary / --current (color), spinner-inline (spinner + texto en linea)  ·  Estados: spinning (estado unico activo: girando continuamente), en boton (.btn--loading reutiliza el atomo y oculta el contenido), reduced-motion (giro deshabilitado, se muestra estatico)
